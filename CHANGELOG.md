# Changelog

## Unreleased

- Playback can switch sources after a failure. Fast, Balanced and Best quality start preferences control the wait for alternatives, and seeking works while a track fills the cache.
- Favorites and playlist entries make provider music available in normal library browsing. Linked listening profiles can share hearts; mixed playlists and offline downloads preserve stable track entries.
- Scheduled Health checks exercise playback without adding synthetic plays to listening history or scrobbles. Backup controls include retention and restore verification.
- A getting-started guide and problem inbox help testers connect clients and report problems with useful context.
- Provider checks distinguish failed checks from missing samples and unverified facts. Source labels distinguish Allstarr items from the service actually delivering their audio, and missing covers use provider artwork.
- Lyrics sources include word timing and visible provider credits. Private keys belong to configured accounts.
- Dashboard access follows current media-server permissions, repeated password checks are limited, and match reviews, extension diagnostics and playlist writes enforce listener privacy and ownership.

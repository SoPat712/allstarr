# Client API v2

Use v2 for new clients. Read [authentication, errors and limits](README.md) first.
Examples assume `BASE=http://localhost:5274`, `ALLSTARR_TOKEN` and IDs copied from
actual responses. The [OpenAPI file](../../apis/specifications/allstarr/client-v2.json)
contains the full JSON schemas. JSON names below use their wire spelling.

## IDs and track shape

Track reads accept any supported ID spelling: the returned v2 `trk_` ID, a native
library item ID, or an older `ext-` song ID. These are aliases, not separate songs.
Two spellings of one recording return one track with both in `aliases`.
Keep the returned `id`; do not construct or decode it. A recording-backed ID
survives keeping, adding to the library and rematching. A later merge can rename
it; follow `track.renamed` events and refresh stored references.

Every `V2Track` has the same shape:

| Fields | Meaning |
| --- | --- |
| `id`, `aliases` | Stable track ID and other accepted spellings. |
| `canonicalRecordingId` | Recording identity shared by library and service copies, or null. |
| `isExternal`, `libraryItemId`, `provider`, `externalIds` | Library identity and known service/recording identifiers. Provider has `id`, `name`, `iconUrl`, `glyphUrl`. |
| `title`, `artists`, `albumArtists`, `featuring`, `album` | Names and references. Artist references have `id`, `name`; album has `id`, `name`, `title`. Reference IDs can be null. |
| `disc`, `track`, `durationMs`, `year`, `explicit` | Recording metadata; unknown values can be null. |
| `artwork` | `{url}`; append `?w=<pixels>` to request a width, clamped to 32–2,048 (default 600). The URL changes with the image. |
| `format` | Stored or measured source facts: `container`, `codec`, `bitrate` in bits/s, `sampleRate` in Hz, `bitDepth`, `channels`, `isLossless`. This does not describe converted playback. |
| `trackGainDb`, `albumGainDb` | ReplayGain values, or null. |
| `saved`, `playCount`, `lastPlayedAt` | This listener's saved and listening state. |
| `keep`, `match`, `lyrics` | `{state,progress}`, optional `{state,confidence,authority}`, and `{available,format,source}`. Lyrics text requires a view. |

## Optional data and validators

`include` adds related resources. `views` adds computed data about a resource.
Names are comma-separated and case-sensitive. Unknown names, duplicate names and
empty list entries return `400`; an omitted or empty value asks for none.

The single-track views are `lyrics`, `lyricsSources`, `match` and `autoplay`.
Track lists support only `lyrics`. Track includes support only `album`.
Album options are separate and described below.

Conditional reads return an `ETag`. Store it with that exact representation,
including its include/view options. Send `If-None-Match` to receive `304` without
a body when it still matches. Responses use `Cache-Control: no-store`; retain
only the private application state your client needs. Conditional reads can
still perform work before comparing the representation.

## Session

### `GET /allstarr/v2/session`

Read `{listener:{id,name},serverVersion,features,dashboard?}`. No parameters.
`features` has boolean keys `tracks`, `albums`, `batch`, `playback`, `events`,
`artistLinks`, `lyricsTranslation`, `autoplay`, `trackFacts`, `lyricsSources`,
`trackMatch`, `appearances`, `similarAlbums` and `playbackStatus`.
`lyricsTranslation` follows the translation setting. `dashboard`, when configured, is `{url}` with the same
public dashboard address as v1 capabilities. Optional header `If-None-Match`.
This read is also available in a batch.

```bash
curl -H "Authorization: Bearer $ALLSTARR_TOKEN" "$BASE/allstarr/v2/session"
```

## Track resources

### `GET /allstarr/v2/tracks`

Read several tracks in requested order. Required query `ids` is a comma-separated
list of 1–100 nonempty IDs. Optional `include=album` adds `albums`, a map keyed by
album ID. Optional `views=lyrics` adds `views` and `viewStatus` maps keyed by the
returned track ID. `If-None-Match` is optional.

Returns `{tracks:[V2Track],missing:[id],albums?,views?,viewStatus?}`. Unknown or
hidden IDs are in `missing`; aliases collapse to one track. Reading tracks
never opens their audio.
Malformed IDs return `400`.
Stored metadata and listener facts are read in batches, including for 100 IDs;
`provider` describes the metadata source, without predicting a playback route.

```bash
curl -G -H "Authorization: Bearer $ALLSTARR_TOKEN" \
  --data-urlencode "ids=$TRACK_ID,$OTHER_TRACK_ID" \
  --data-urlencode 'include=album' --data-urlencode 'views=lyrics' \
  "$BASE/allstarr/v2/tracks"
```

### `GET /allstarr/v2/tracks/{id}`

Read one track by any accepted spelling. Optional query `include=album`,
`views=lyrics,lyricsSources,match,autoplay` and header `If-None-Match`.
Choose only the views you need. Unknown or hidden tracks return `404`.

Returns `{track:V2Track,albums?,views?,viewStatus?}`. View fields with no data are
omitted. `viewStatus` reports each requested view as `ok`, `none`, `unavailable`
or, for autoplay, `partial`. A failed view does not discard the track.

| View | Shape |
| --- | --- |
| `lyrics` | `{source,format,lines:[{startMs,endMs,text,part,words:[{startMs,endMs,text}],voice?,singer?}]}`. Unknown line timing and word end times remain null. |
| `lyricsSources` | `{sources,chosen,revision}` using `ClientLyricsSources` from the schema. |
| `match` | `{state,confidence,authority,current,candidates,revision}` using `ClientItemMatch`. |
| `autoplay` | `{tracks:[V2Track],next}` with up to 25 tracks initially. Follow its continuation resource. |

This read never opens audio, even with views. Use playback resolution when the
listener intends to play or prefetch a song.

```bash
curl -H "Authorization: Bearer $ALLSTARR_TOKEN" \
  "$BASE/allstarr/v2/tracks/$TRACK_ID?include=album&views=lyrics,lyricsSources,match,autoplay"
```

### `GET /allstarr/v2/tracks/{id}/lyrics/translation`

Translate the lines from the lyrics view while preserving their order. Optional
query `to` is a BCP-47 language such as `en`, `es` or `pt-BR`, default `en`.
Invalid languages return `400`. Optional header `If-None-Match`.
Disabled translation, a hidden track or absent lyrics returns `404`.

Returns `{trackId,to,provider,lines:[{index,source,text,from}]}`. Each original
line has one entry, including blank lines. `text` is null when no translation
is needed or a result is dropped. `from` can be null. `provider` is `google`,
`mymemory`, `libretranslate` or null. Results are shared for 30 days by track,
lyrics text and target language. Translation does not add timing.

```bash
curl -H "Authorization: Bearer $ALLSTARR_TOKEN" \
  "$BASE/allstarr/v2/tracks/$TRACK_ID/lyrics/translation?to=es"
```

### `GET /allstarr/v2/tracks/{id}/lyrics/sources`

Read `{sources,chosen,revision}` with the same version, ranking and choice
semantics as the lyrics sources view. Optional `includeLyrics=true` includes
each version's rich lyrics. `chosen` has `{sourceId,layer}`; `revision` has
`personal` and `household` stamps, each null or `{id,revision}`. Optional header
`If-None-Match`. Hidden or unknown tracks return `404`; malformed IDs return
`400`. This read is also available in a batch.

```bash
curl -H "Authorization: Bearer $ALLSTARR_TOKEN" \
  "$BASE/allstarr/v2/tracks/$TRACK_ID/lyrics/sources?includeLyrics=true"
```

### `PUT /allstarr/v2/tracks/{id}/lyrics/source`

Choose a version for this listener with `{sourceId,expectedRevision}`. Copy the
revision object from the sources read. Returns `{chosen,revision}`. A stale
revision or unavailable version returns `409`; missing fields return `400`.

```bash
curl -X PUT -H "Authorization: Bearer $ALLSTARR_TOKEN" -H 'Content-Type: application/json' \
  --data "{\"sourceId\":\"$SOURCE_ID\",\"expectedRevision\":$LYRICS_REVISION}" \
  "$BASE/allstarr/v2/tracks/$TRACK_ID/lyrics/source"
```

### `DELETE /allstarr/v2/tracks/{id}/lyrics/source`

Clear this listener's choice and restore the household choice or automatic
selection. Body: `{expectedRevision}`, using the latest sources or selection
response. Returns `{chosen,revision}`. Stale revisions return `409`.

```bash
curl -X DELETE -H "Authorization: Bearer $ALLSTARR_TOKEN" -H 'Content-Type: application/json' \
  --data "{\"expectedRevision\":$LYRICS_REVISION}" \
  "$BASE/allstarr/v2/tracks/$TRACK_ID/lyrics/source"
```

### `GET /allstarr/v2/tracks/{id}/match`

Read `{state,confidence,authority,current,candidates,revision}`. Candidates carry
opaque `candidateId` handles, recording metadata, provider, confidence and
reasons. No parameters. Optional header `If-None-Match`. Tracks without a visible
match return `404`; malformed track IDs return `400`. Available in a batch.

```bash
curl -H "Authorization: Bearer $ALLSTARR_TOKEN" \
  "$BASE/allstarr/v2/tracks/$TRACK_ID/match"
```

### `PUT /allstarr/v2/tracks/{id}/match`

Pin `{candidateId,expectedRevision}` from the match read for this listener.
Returns the updated match. A stale revision returns `409`; an unavailable
candidate returns `400`. Administrator tokens also create personal choices here.

```bash
curl -X PUT -H "Authorization: Bearer $ALLSTARR_TOKEN" -H 'Content-Type: application/json' \
  --data "{\"candidateId\":\"$CANDIDATE_ID\",\"expectedRevision\":\"$MATCH_REVISION\"}" \
  "$BASE/allstarr/v2/tracks/$TRACK_ID/match"
```

### `DELETE /allstarr/v2/tracks/{id}/match`

Clear this listener's override, restoring the household or automatic match.
Required query `expectedRevision` is the opaque revision from the latest match
response. Returns the updated match; stale revisions return `409`.

```bash
curl -X DELETE -G -H "Authorization: Bearer $ALLSTARR_TOKEN" \
  --data-urlencode "expectedRevision=$MATCH_REVISION" \
  "$BASE/allstarr/v2/tracks/$TRACK_ID/match"
```

### `POST /allstarr/v2/tracks/{id}/match/reject`

Reject the effective match for this listener with `{expectedRevision}`. Returns
the updated match, with `state:rejected` and null `current`. Stale revisions
return `409`.

```bash
curl -X POST -H "Authorization: Bearer $ALLSTARR_TOKEN" -H 'Content-Type: application/json' \
  --data "{\"expectedRevision\":\"$MATCH_REVISION\"}" \
  "$BASE/allstarr/v2/tracks/$TRACK_ID/match/reject"
```

### `GET /allstarr/v2/tracks/{id}/appearances`

Read `{trackId,songCount,appearances}` for this listener's mixes and synced
playlists containing the track. Each appearance has
`{kind,id,title,subtitle,coverUrl,matchedSongCount,playlistId}`. IDs use v2 track,
mix and playlist spellings. No parameters. Optional header `If-None-Match`.
Hidden tracks return `404`; malformed IDs return `400`. Available in a batch.

```bash
curl -H "Authorization: Bearer $ALLSTARR_TOKEN" \
  "$BASE/allstarr/v2/tracks/$TRACK_ID/appearances"
```

### `GET /allstarr/v2/tracks/{id}/autoplay`

Continue a queue after a seed track. Optional query `limit` is 1–50, default 25;
`cursor` is the opaque `next` value from the previous page. Optional header
`If-None-Match`. Keep the seed ID unchanged while following pages.

Returns `{tracks:[V2Track],next}`. It tries native InstantMix or service radio,
similar songs, the artist, then the album. Pages avoid repeats within the bounded
continuation history. A partial page can be empty and still have `next`; null
means exhausted. A malformed cursor or a cursor for another seed returns `400`.

```bash
curl -G -H "Authorization: Bearer $ALLSTARR_TOKEN" \
  --data-urlencode "cursor=$CURSOR" --data-urlencode 'limit=25' \
  "$BASE/allstarr/v2/tracks/$TRACK_ID/autoplay"
```

## Album resource

### `GET /allstarr/v2/albums/{id}`

Read a native or service album using its v2 or older album ID. Optional
`include=tracks` adds native v2 track shapes in disc and track order.
Optional `views=more-by-artist` adds up to 20 other albums from the first
identified album artist. Optional header `If-None-Match`.

Returns `{album,tracks?,missing?,views?:{moreByArtist:[album]}}`. Album summaries
have `{id,title,artists,year,isExternal,artwork}`. `missing` lists requested album
tracks that could not be returned. Unknown albums return `404`; unknown option
names return `400`.

```bash
curl -H "Authorization: Bearer $ALLSTARR_TOKEN" \
  "$BASE/allstarr/v2/albums/$ALBUM_ID?include=tracks&views=more-by-artist"
```

### `GET /allstarr/v2/albums/{id}/similar`

Read `{albumId,basedOn,albums}` using the same related-artist picks as v1,
preferring library albums when available. Optional `limit` is 1–24, default 12.
Albums have the usual v2 summary fields plus `songCount`, `source` and
`provider`. Optional header `If-None-Match`. Hidden or unknown albums return
`404`; malformed IDs and invalid limits return `400`. Available in a batch.

```bash
curl -H "Authorization: Bearer $ALLSTARR_TOKEN" \
  "$BASE/allstarr/v2/albums/$ALBUM_ID/similar?limit=12"
```

## Batched reads

### `POST /allstarr/v2/batch`

Read several resources in one round trip. Endpoints are resources, not screens:
the client chooses the combination. Batch dispatches the same ordinary GET
readers and gives each item its own status. One failed read never fails the others.

Body: `{requests:[{id,path,ifNoneMatch?}]}` with 1–20 items. IDs must be unique,
1–64 characters. Each `path` is a relative v2 path with its query, at most 8,192
characters. An optional `ifNoneMatch` carries the stored ETag for that read.

The fixed allowlist contains session, track list, single track, lyrics sources,
match, appearances, track translation, track autoplay, album, similar albums and
playback status reads above. Their documented query options are allowed.
It excludes artist links, events, ping, stream access and playback resolution.
The fixed allowlist contains the track list, single track, track translation,
track autoplay, album, mix list, mix tracks, releases, library additions and
karaoke model metadata reads. Their documented query options are allowed.
It excludes artist links, events, ping, covers, provider icons, model downloads,
stream access and playback resolution.
No method field or arbitrary URL is accepted. Unsupported paths return per-item
`404`; invalid options on an allowed path return per-item `400`.

Returns HTTP `200` with `{responses:{<id>:{status,body?,etag}}}`. Each successful
body is the same shape as the standalone route. Errors have `{code,error}`.
A matching `ifNoneMatch` produces per-item `304`, its ETag and no body.
An invalid outer envelope, including duplicate IDs, returns outer `400`.

```bash
curl -H "Authorization: Bearer $ALLSTARR_TOKEN" -H 'Content-Type: application/json' \
  --data "{\"requests\":[{\"id\":\"song\",\"path\":\"/allstarr/v2/tracks/$TRACK_ID?views=lyrics\"},{\"id\":\"album\",\"path\":\"/allstarr/v2/albums/$ALBUM_ID?include=tracks\"}]}" \
  "$BASE/allstarr/v2/batch"
```

## Playback resources

### `POST /allstarr/v2/playback/resolve`

Select a source and delivered format, then return a signed stream link valid for
12 hours. Body limit: 8 KiB.

| Body field | Values |
| --- | --- |
| `trackId` | Required track ID in any accepted spelling, at most 1,024 characters. |
| `tier` | Required: `lossless`, `high`, `normal`, `low` or `original`. Household and listener quality limits still apply. |
| `client` | Optional `{codecs:[string],maxSampleRate?,maxBitDepth?,channels?}`. At most 16 codecs; sample rate 8,000–384,000 Hz, depth 8–32, channels 1–8. |
| `purpose` | Optional `play`, `prefetch`, `download` or `cast`. Use `prefetch` for the next song; it can warm the external source in cache. |

Returns `{url,expiresAt,playbackId,cacheKey,source,delivered,transcoded,
contentLength,seek,trackGainDb,albumGainDb,provider,routeReason,loweredBy,serving}`.
`source` and `delivered` each have `{container,codec,bitrate,sampleRate,bitDepth,
isLossless}`. `provider` has `{id,name}`. `loweredBy` identifies a household or
listener quality limit, or is null. `serving`, when present, describes the caller's
active stream as `{codec,bitrate,bitDepth,sampleRate,source}`.

`cacheKey` hashes track, requested tier, delivered format and source identity;
it excludes the listener and signed token. Equal inputs produce the same key.
`seek=bytes` permits range resumes. `seek=none` does not. Live transcodes have
null `contentLength`, ignore Range and return a full `200` stream. A lossless
request can fall back; inspect `delivered` and `routeReason`.

Reading a track never opens audio. Resolve performs source inspection explicitly.
Prefetch can move audio into cache without invalidating the returned link.

```bash
curl -H "Authorization: Bearer $ALLSTARR_TOKEN" -H 'Content-Type: application/json' \
  --data "{\"trackId\":\"$TRACK_ID\",\"tier\":\"lossless\",\"purpose\":\"prefetch\",\"client\":{\"codecs\":[\"flac\",\"aac\"]}}" \
  "$BASE/allstarr/v2/playback/resolve"
```

### `GET /allstarr/v2/playback/{playbackId}`

Read `{playbackId,delivered,serving}` for the ID returned by resolve.
Both `delivered` and `serving` are null before the stream opens and after it
closes. While open, `delivered` describes the actual delivered format and
`serving` has the actual
`{source,codec,bitrate,sampleRate,bitDepth}`. `source` identifies the serving
service. A second resolve of the same track has its own playback status.

This read never opens audio, issues a link or prepares a source. No parameters.
Optional header `If-None-Match`. Another listener's or unknown playback returns
`404`; a malformed playback ID returns `400`. Status is held in memory for up
to 12 hours and is lost on restart or eviction. Available in a batch.

```bash
curl -H "Authorization: Bearer $ALLSTARR_TOKEN" \
  "$BASE/allstarr/v2/playback/$PLAYBACK_ID"
```

### `GET /allstarr/v2/stream/{token}`

Open the exact `url` returned by resolve. The signed path token authorizes the
track, tier and delivered format; a Jellyfin authorization header is unnecessary.
Do not build this URL yourself. Bad, expired or foreign tokens return `404`.

Returns audio with `200`, or `206` for a supported byte range. Stored files and
pass-through sources can support ranges when resolve advertises `seek=bytes`.
Live transcodes ignore Range. The source can move from provider to cache after
prefetch. `STREAM_URL` below is the returned URL.

```bash
curl -H 'Range: bytes=0-65535' "$STREAM_URL" --output sample.audio
```

### `HEAD /allstarr/v2/stream/{token}`

Inspect the signed media link's headers without returning an audio body.
Uses the same token and expiry rules. Success is `200`; an invalid link is `404`.
Length and range headers depend on the selected delivery.

```bash
curl -I "$STREAM_URL"
```

## Listener events

### `HEAD /allstarr/v2/ping`

Check reachability while the event stream is disconnected. Requires the Bearer
header. No parameters. Returns `204` without a body.

```bash
curl -I -H "Authorization: Bearer $ALLSTARR_TOKEN" "$BASE/allstarr/v2/ping"
```

### `GET /allstarr/v2/events`

Open a listener-scoped server-sent event stream with a Bearer header.
Optional `Last-Event-ID` header takes precedence over the `lastEventId` query
cursor. It replays up to 1,000 retained events within ten minutes. Unknown or
expired cursors produce `resync` with `{}`: refetch state, then continue live.
Replay is held in memory. Comments ping every 25 seconds.

Returns `text/event-stream` frames with increasing `id`, `event` and JSON `data`.
Save the last received event ID. Reconnect with that cursor. The stream shares
the v1 connection limits in the [API overview](README.md#limits-and-retries).

| Event | Data |
| --- | --- |
| `track.updated` | `{track:V2Track}` |
| `lyrics.updated` | `{trackId,revision}`; reread the lyrics view. |
| `match.updated` | `{trackId,state}` |
| `keep.updated` | `{trackId,state,progress?}` |
| `mix.updated` | `{mixId,playlistId}` |
| `releases.updated` | `{count}` |
| `libraryAddition.updated` | `{row}` using the v1 library-addition shape. |
| `track.renamed` | `{old,new}`; reaches currently connected v2 listeners. |
| `resync` | `{}` |

```bash
curl -N -H "Authorization: Bearer $ALLSTARR_TOKEN" \
  -H "Last-Event-ID: $EVENT_ID" "$BASE/allstarr/v2/events"
```

## Artist links

These resources connect a library artist to service artist identities. Library
IDs can be native or v2 artist IDs; service IDs can be v2 or older `ext-` artist
IDs. The library side must resolve to an accessible Jellyfin `MusicArtist`.

Responses use `{links:[link],notSame:[link]}`. Each link has
`{id,aliases,source,sourceName,by,scope}`. `by` is `songs` for matched-song
evidence or `fix` for a person's choice. Fix scope is `household` or `you`;
computed evidence has null scope. A personal choice wins over a household choice.

### `GET /allstarr/v2/artists/{libraryArtistId}/links`

Read linked service artists and explicitly rejected identities. No query
parameters. Returns the artist-links response; inaccessible artists return `404`.

```bash
curl -H "Authorization: Bearer $ALLSTARR_TOKEN" \
  "$BASE/allstarr/v2/artists/$LIBRARY_ARTIST_ID/links"
```

### `PUT /allstarr/v2/artists/{libraryArtistId}/links/{serviceArtistId}`

Set `{same:true}` for the same artist or `{same:false}` for a different act.
An administrator's answer covers the household; a listener's covers only them.
Search and artist pages use the new choice immediately. Returns the updated
artist-links response. Invalid service IDs return `400`.

```bash
curl -X PUT -H "Authorization: Bearer $ALLSTARR_TOKEN" -H 'Content-Type: application/json' \
  --data '{"same":true}' \
  "$BASE/allstarr/v2/artists/$LIBRARY_ARTIST_ID/links/$SERVICE_ARTIST_ID"
```

### `DELETE /allstarr/v2/artists/{libraryArtistId}/links/{serviceArtistId}`

Remove the caller's saved choice and let underlying evidence apply again.
No body or query parameters. Returns the updated artist-links response.
An administrator can remove the household choice using the same authority as
PUT. A listener cannot remove a household-only choice (`403`); they can save a
personal `same:false` choice instead.

```bash
curl -X DELETE -H "Authorization: Bearer $ALLSTARR_TOKEN" \
  "$BASE/allstarr/v2/artists/$LIBRARY_ARTIST_ID/links/$SERVICE_ARTIST_ID"
```

## Mixes

### `GET /allstarr/v2/mixes`

Read this listener's stored mixes. Optional `timeZoneId` selects the time zone
for dated mixes; an invalid zone returns `400`. Service feeds appear only when
added to apps. Reading mixes does not generate them. Supports batch and ETags.

Returns `{mixes:[{id,kind,name,description,state,itemCount,durationMs,updatedAt,
coverUrl,inApps,playlistId,section,source,sourcePlaylistId,appsUnavailableReason}]}`.
`state` is `ready`, `empty`, `building` or `needs-listening`. `playlistId` is a
v2 playlist ID when published to apps, otherwise null. Open the returned
`coverUrl` with the listener's authorization header.

```bash
curl -H "Authorization: Bearer $ALLSTARR_TOKEN" \
  "$BASE/allstarr/v2/mixes?timeZoneId=UTC"
```

### `GET /allstarr/v2/mixes/{id}/tracks`

Read tracks in stored mix order. Accepts the returned v2 mix ID or its older
UUID. Returns `{id,updatedAt,tracks:[V2Track],missing:[id]}`. Tracks use the same
listener state and identity as other v2 track reads. Hidden mixes return `404`;
malformed IDs return `400`. Supports batch and ETags.

```bash
curl -H "Authorization: Bearer $ALLSTARR_TOKEN" \
  "$BASE/allstarr/v2/mixes/$MIX_ID/tracks"
```

### `GET /allstarr/v2/mixes/{id}/cover`

Read a mix cover as JPEG or PNG. Use the returned cover URL, including its
optional `v` version. A current version enables immutable private caching;
unversioned or stale URLs require revalidation. Supports `If-None-Match` and
returns `304` when unchanged. Partial collages retain a short private cache
lifetime while missing pictures are retried. Hidden mixes return `404`; invalid IDs or version
values return `400`. Excluded from batch.

```bash
curl -H "Authorization: Bearer $ALLSTARR_TOKEN" \
  "$BASE$MIX_COVER_URL" --output mix-cover.jpg
```

## Releases and follows

### `GET /allstarr/v2/releases`

Read stored releases for this listener and the artists they follow. Returns
`{releases:[{id,title,kind,releaseDate,artist,albumId,coverUrl}],followedArtists}`.
Artists have `{id,name,imageUrl}`; artist and album IDs use v2 spellings.
Release IDs identify entries in the listener's release inbox. Supports batch
and ETags.

```bash
curl -H "Authorization: Bearer $ALLSTARR_TOKEN" "$BASE/allstarr/v2/releases"
```

### `GET /allstarr/v2/releases/{id}/cover`

Read artwork for a release in this listener's inbox. Open its `coverUrl` with
the authorization header. Returns an image, or `204` when artwork is unavailable.
Supports `If-None-Match` and `304`. Hidden releases return `404`; malformed
release IDs return `400`. Excluded from batch.

```bash
curl -H "Authorization: Bearer $ALLSTARR_TOKEN" \
  "$BASE$RELEASE_COVER_URL" --output release-cover.png
```

### `PUT /allstarr/v2/artists/{id}/follow`

Follow an accessible library or service artist for new releases. Accepts a v2
or older artist ID. Returns `{followed:true,artist:{id,name,imageUrl}}`.
Repeating the request preserves the same follow. Hidden or unresolvable artists
return `404`; malformed IDs return `400`.

```bash
curl -X PUT -H "Authorization: Bearer $ALLSTARR_TOKEN" \
  "$BASE/allstarr/v2/artists/$ARTIST_ID/follow"
```

### `DELETE /allstarr/v2/artists/{id}/follow`

Remove this listener's follow. No body. Returns
`{followed:false,artist:{id,name,imageUrl}}`. Repeating the request is safe.
Hidden artists return `404`; malformed IDs return `400`.

```bash
curl -X DELETE -H "Authorization: Bearer $ALLSTARR_TOKEN" \
  "$BASE/allstarr/v2/artists/$ARTIST_ID/follow"
```

## Library additions

### `GET /allstarr/v2/library/additions`

Read only this listener's additions, newest first. Supports batch and ETags.
Returns an array of `{id,itemId,unit,state,reason,libraryItemId?,requestedItemId?}`.
`itemId` is the canonical v2 track ID; `requestedItemId` identifies the original
track or album. `libraryItemId`, when present, is the accessible native library
item created by the addition. States are `waitingForApproval`, `adding`, `done`,
`needsLook`, `declined` and `cancelled`.

```bash
curl -H "Authorization: Bearer $ALLSTARR_TOKEN" \
  "$BASE/allstarr/v2/library/additions"
```

### `POST /allstarr/v2/library/additions`

Body: `{itemId,unit}`, where `unit` is `song` or `album`. Accepts a v2 or older
track ID, or an album ID with `unit=album`. Uses the listener's library profile,
destination permissions and approval rules. Returns `202` with the addition.
Body limit: 8 KiB.

Optional `Idempotency-Key` is a nonempty retry key of at most 300 characters.
Replaying the same request within 24 hours returns `200` and the saved addition;
changing its item or unit returns `409`. Invalid input returns `400`; hidden
items or destinations return `404`.

```bash
curl -H "Authorization: Bearer $ALLSTARR_TOKEN" -H 'Content-Type: application/json' \
  -H "Idempotency-Key: $REQUEST_KEY" \
  --data "{\"itemId\":\"$TRACK_ID\",\"unit\":\"song\"}" \
  "$BASE/allstarr/v2/library/additions"
```

### `DELETE /allstarr/v2/library/additions/{id}`

Cancel this listener's pending request or running addition. No body. Returns
the updated addition. Files already added stay in the library. Another
listener's ID returns `404`; malformed UUIDs return `400`; an addition that
cannot be cancelled returns `409`.

```bash
curl -X DELETE -H "Authorization: Bearer $ALLSTARR_TOKEN" \
  "$BASE/allstarr/v2/library/additions/$ADDITION_ID"
```

## Reports

### `POST /allstarr/v2/reports`

Create a problem report. Body: `{kind,note,itemId?,playbackRequestId?}`. `kind`
is `wrong-song`, `wrong-lyrics`, `wont-play`, `bad-quality`, `wrong-info` or
`other`. `note` is 1–2,000 characters. `itemId` accepts a track ID in any
supported spelling. Returns `201` with `{id}`. Body limit: 16 KiB.

An optional playback request ID must belong to this listener and device;
unavailable or foreign context returns `404`. Without it, current playback on
the caller's device can supply context. The existing MediaBrowser authorization
header can carry `DeviceId` for this purpose. Invalid fields return `400`.

```bash
curl -H "Authorization: Bearer $ALLSTARR_TOKEN" -H 'Content-Type: application/json' \
  --data "{\"kind\":\"wrong-info\",\"note\":\"The title is incorrect\",\"itemId\":\"$TRACK_ID\"}" \
  "$BASE/allstarr/v2/reports"
```

## Karaoke models

### `GET /allstarr/v2/models/karaoke`

Read the current validated model. Returns
`{version,sha256,sizeBytes,computeUnits,format,url,license}`. The versioned `url`
points to the v2 file resource. No available model returns `404`. Supports batch
and ETags.

```bash
curl -H "Authorization: Bearer $ALLSTARR_TOKEN" \
  "$BASE/allstarr/v2/models/karaoke"
```

### `GET /allstarr/v2/models/karaoke/{version}/file`

Download a validated model with the authorization header. Returns
`application/octet-stream` with attachment filename, immutable private caching
and a SHA-256 ETag. Byte ranges return `206`; invalid ranges return `416`;
`If-None-Match` can return `304`. Unknown versions return `404`; unsafe version
segments return `400`. Excluded from batch.

```bash
curl -H "Authorization: Bearer $ALLSTARR_TOKEN" \
  "$BASE$MODEL_URL" --output karaoke-model.aar
```

## Provider icons

### `GET /allstarr/v2/providers/{id}/icon`

Read installed provider artwork. Optional `variant=color|glyph` defaults to
`color`; optional `format=svg|png` selects an available format. Omitted format
uses the available default. SVG is served directly; raster assets are resized
to `size`, 16–256 pixels, default 96. Returns SVG or PNG with a private cache
policy and ETag. Supports `If-None-Match` and `304`. Unknown providers or absent
variants return `404`; invalid parameters return `400`. Excluded from batch.

V2 track providers and match candidates use this resource for `iconUrl` and
`glyphUrl`.

```bash
curl -H "Authorization: Bearer $ALLSTARR_TOKEN" \
  "$BASE/allstarr/v2/providers/$PROVIDER_ID/icon?variant=glyph&format=png&size=96" \
  --output provider-icon.png
```
